The server that wins the Crossdown is the one that has generated the most points during the period. Server score points are generated each time a player from the server earns points. Note that there are 4 relics present for all 4 servers. At the opening, each server has one relic, and each owned relic increases the points generated by the server by 20%, up to 80%.
